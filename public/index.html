      Gọi API dịch

      POST /api/v1/translate

      Lấy danh sách model: GET /api/v1/models, dùng cùng header Authorization.
      Dịch tệp: POST /api/v1/translate-file, trả về NDJSON gồm start, progress và done.
      Thuật ngữ đã lưu được áp dụng tự động cho cả API token, theo target của yêu cầu.
      Token hợp lệ không bị giới hạn số lượt gọi. Mỗi yêu cầu văn bản tối đa 20.000 ký tự; mỗi tệp tối đa 10 MB và 20.000 mục. source mặc định là auto; target mặc định là vi.
